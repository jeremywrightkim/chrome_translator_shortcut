# 번역 단축키

크롬에서 단축키 하나(기본 `Alt+T`)로 **크롬 기본 페이지 번역**을 켜고 끄는 Windows 트레이 프로그램입니다.

우클릭 → "한국어(으)로 번역"이나 주소창 번역 아이콘 → "한국어"를 누르는 과정을 대신 해 줍니다. 크롬 자체 번역 기능을 그대로 쓰므로 번역 결과는 크롬 기본 번역과 같습니다.

## 사용법

1. `bin\TranslatorShortcut.exe`를 실행하면 작업 표시줄 오른쪽 트레이에 아이콘이 생깁니다.
2. 크롬에서 `Alt+T`를 누르면 한국어로 번역되고, 다시 누르면 원문으로 돌아옵니다.

번역할 언어는 크롬 설정을 따릅니다 (`chrome://settings/languages` → Google 번역).

단축키는 **크롬 창이 맨 앞에 있을 때만** 등록됩니다. 다른 프로그램에서는 같은 키를 그대로 쓸 수 있습니다.

### 트레이 메뉴

| 메뉴 | 설명 |
|---|---|
| 환경설정… | 환경설정 창 열기. 트레이 아이콘을 두 번 클릭하거나, **이미 실행 중일 때 exe를 다시 실행해도** 열림 |
| 로그 폴더 열기 | 설정, 인식 정보, 오류 로그가 있는 `%APPDATA%\TranslatorShortcut` 열기 |
| 종료 | 프로그램 종료 |

Windows 11은 새 트레이 아이콘을 숨김 영역(^)에 넣으므로, 아이콘을 찾기 어려우면 exe를 한 번 더 실행하세요.

### 환경설정

| 항목 | 설명 |
|---|---|
| 단축키 | 입력 칸을 누른 뒤 새 키 조합을 누릅니다. Ctrl 또는 Alt가 들어간 조합이나 F1~F24 키를 쓸 수 있습니다 |
| Windows 시작 시 자동 실행 | 로그인할 때 자동으로 실행 |
| 호환성 검사 | 마지막으로 쓰던 크롬 창을 **읽기만 해서** 동작 조건을 확인합니다 (아래 참고) |
| 보정… | 크롬 화면 요소를 사용자 환경에 맞춰 다시 인식시킵니다 (아래 참고) |
| 기본값으로 되돌리기 | 보정한 인식 정보를 지우고 기본값(크롬 154, 한국어 기준)으로 돌아갑니다 |
| 인식 정보 파일 열기 | 인식 정보 파일을 메모장으로 엽니다. 고친 내용은 환경설정 창을 닫을 때 적용됩니다 |

단축키와 자동 실행은 [확인]을 눌러야 적용되고, 보정과 기본값 복원은 바로 적용됩니다.

## 크롬 환경이 다를 때

크롬 버전이나 설정에 따라 화면 요소의 이름이 달라질 수 있습니다. 단축키가 동작하지 않으면 다음 순서로 확인합니다.

### 1. 호환성 검사

크롬을 조작하지 않고 다음을 확인해 정상 / 참고 / 주의 / 문제로 보여 줍니다.

- 크롬 창과 버전
- 조직 정책으로 번역이 차단됐는지 (`TranslateEnabled` 정책)
- 크롬 설정의 "Google 번역 사용"이 꺼진 프로필이 있는지
- 화면 구조, 툴바, 크롬 메뉴 버튼, 웹페이지 영역, 주소창 번역 아이콘을 찾을 수 있는지
- 보정 이후 크롬 버전이 바뀌었는지

번역 창과 메뉴 항목은 열어야 보이므로 검사하지 않습니다.

### 2. 보정

크롬에서 외국어 페이지를 열어 두고 [보정…] → [시작]을 누른 뒤, 안내에 따라 크롬을 직접 클릭합니다.

1. 주소창의 번역 아이콘
2. 번역 창의 "한국어" 탭 (페이지가 번역됨)
3. 번역 창의 원래 언어 탭 (원문으로 돌아옴)
4. 번역 창의 닫기(X) 버튼
5. 크롬 메뉴 버튼(⋮) — 건너뛸 수 있음
6. 메뉴의 "번역…" — 건너뛸 수 있음

클릭한 요소의 이름과 클래스 이름을 기록합니다. 엉뚱한 곳을 클릭하면 다시 클릭하도록 안내합니다. 닫기 버튼과 메뉴 항목은 실제로 번역 창이 닫히고 열리는지 확인한 뒤에 넘어갑니다. [저장]을 누르면 `%APPDATA%\TranslatorShortcut\chrome-profile.txt`에 저장되어 바로 적용됩니다.

보정은 **이름이 바뀐 경우**에 대응합니다. 번역 창이 탭 대신 다른 방식으로 바뀌는 것처럼 크롬의 동작 자체가 달라지면 프로그램을 고쳐야 합니다.

## 동작 방식

Windows UI Automation으로 크롬 화면을 조작합니다.

1. 크롬 번역 창을 엽니다. 주소창의 번역 아이콘을 누르고, 아이콘이 없으면 크롬 메뉴(⋮)의 "번역…"을 누릅니다.
2. 번역 창의 언어 탭 두 개(원문 언어, 번역할 언어) 중 지금 선택되지 않은 쪽을 선택합니다.
3. 번역 창을 닫고, 키보드 포커스를 단축키를 누르기 전 위치(웹페이지, 주소창 등)로 되돌립니다.

요소를 찾는 이름과 클래스 이름은 인식 정보(기본값 또는 보정 결과)를 따릅니다. 실패하면 트레이 알림이 뜨고, 로그(`%APPDATA%\TranslatorShortcut\log.txt`)에 실패한 단계와 크롬 버전이 남습니다.

## 요구 사항

- Windows 10 또는 11 (.NET Framework 4.x는 Windows에 기본 포함)
- 기본 인식 정보는 한국어 크롬 154 기준입니다. 다른 환경은 [보정]으로 맞춥니다.

## 빌드

별도 SDK 없이 Windows에 들어 있는 C# 컴파일러로 빌드합니다.

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

`bin\TranslatorShortcut.exe`가 만들어집니다. 아이콘을 다시 그리려면 `assets\app.ico`를 지우고 빌드하거나 `tools\make-icon.ps1`을 실행합니다.

## 파일 구성

| 파일 | 역할 |
|---|---|
| `src\Program.cs` | 진입점. 중복 실행 시 실행 중인 프로그램의 환경설정 창을 엶 |
| `src\TrayApp.cs` | 트레이 아이콘과 메뉴, 단축키 등록/해제, 번역 전환 실행 |
| `src\ChromeTranslator.cs` | 번역 창을 열고 언어 탭을 바꿔 번역과 원문을 전환 |
| `src\ChromeUi.cs` | 인식 정보에 따라 크롬 화면 요소를 찾는 공통 기능 |
| `src\ChromeProfile.cs` | 인식 정보(요소 이름과 클래스 이름)의 기본값, 읽기, 저장 |
| `src\CompatibilityChecker.cs` | 호환성 검사 |
| `src\Calibration.cs` | 보정: 클릭 감지(마우스 훅), 클릭한 요소 기록, 단계별 판정 |
| `src\CalibrationForm.cs` | 보정 안내 창 |
| `src\SettingsForm.cs` | 환경설정 창 |
| `src\HotkeyBox.cs` | 단축키 입력 칸 |
| `src\ChromeWindow.cs` | 크롬 창 판별, 검사·보정할 크롬 창 찾기, 크롬 버전 |
| `src\Hotkeys.cs` | 단축키 검사, 표시, 저장 형식 |
| `src\Settings.cs` | 설정 파일, 자동 실행 등록, 로그 |
| `src\NativeMethods.cs` | Win32 API 선언 |
| `assets\` | 아이콘, 앱 매니페스트 |
| `tools\make-icon.ps1` | 아이콘 생성 |
| `build.ps1` | 빌드 |
